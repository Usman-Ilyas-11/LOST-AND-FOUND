# Lost and Found Management System

A desktop-based **Lost and Found Management System** developed using **C# WinForms** with **Guna UI** for a modern user interface and **SQLite** as the backend database. The application supports two roles—**Admin** and **Student**—to efficiently manage, track, and resolve lost and found items within an institution.

---

## Features

### Role-Based Login

* Secure login system with two roles:

  * **Admin**
  * **Student**

---

### Admin Functionalities

* View all **Lost Items** and **Found Items**
* Match lost items with found items
* Update item status (e.g., Pending, Matched, Returned)
* Manage and monitor the overall lost-and-found workflow

---

### Student Functionalities

* Report a **Lost Item**
* Report a **Found Item**
* View the status of reported items
* Track whether an item has been matched or returned

---

## Technology Stack

* **Language:** C#
* **Framework:** .NET (WinForms)
* **UI Library:** Guna UI
* **Database:** SQLite
* **Architecture:** Desktop Application (Client-side with local database)

---

## Application Overview

* Intuitive and user-friendly desktop interface
* Role-based access control
* Persistent data storage using SQLite

## Database

* SQLite is used for lightweight and efficient local data storage
* Stores users, lost items, found items, and item statuses
